## About Me

I got into computers the usual way — something broke, I got curious about why, and I never really stopped poking around inside machines since.

Most of my time goes into hardware: building PCs, swapping parts, figuring out weird issues, and chasing down driver problems. Software troubleshooting scratches the same itch — there's something satisfying about narrowing a problem down to its actual cause.

Programming came later, almost as a side effect of wanting to build small tools instead of just using other people's. I don't chase frameworks for the sake of it; I pick things up when a project actually needs them.
